# 연수 안내 홈페이지

선생님들이 로그인 없이 접속하는 연수 안내 홈페이지입니다. 넷리파이(Netlify)에 올려서 씁니다.

- 홈페이지: `https://내사이트.netlify.app/`
- 관리자: `https://내사이트.netlify.app/admin` (비밀번호 필요)

## 올리는 방법 (GitHub 연결, 가장 쉬운 방법)

1. GitHub에서 새 저장소를 만들고, 이 폴더의 파일을 그대로 올립니다.
   (`public` 폴더, `netlify` 폴더, `netlify.toml`, `package.json`)
2. 넷리파이에서 **Add new site → Import an existing project**로 그 저장소를 고릅니다.
   설정은 그대로 두면 됩니다. (`netlify.toml`에 이미 적혀 있어요.)
3. **Site configuration → Environment variables**에서 변수를 추가합니다.
   - 이름: `ADMIN_PASSWORD`
   - 값: 내가 정한 관리자 비밀번호
4. **Deploys**에서 한 번 더 배포(Trigger deploy)합니다.
5. `/admin`에 접속해 비밀번호로 로그인합니다.

데이터(글, 설문 응답, 사진)는 넷리파이 내장 저장소(Netlify Blobs)에 저장돼서 따로 가입할 곳이 없습니다.

## 관리자 화면에서 하는 일

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 게시글 | 공지 글, 링크, 복사용 글, 사진, QR 올리기 · 고정 · 삭제 |
| 링크·주소 | 상시 링크와 주소 등록 · 삭제 |
| 설문 | 설문 만들기, 입장 설문 지정, 지금 띄우기, 응답 수 확인, 결과 공개, 마감 |
| 타이머 | 활동 시간 타이머 |
| 질문 | 선생님들이 남긴 질문 확인 · 삭제 |
| 페이지 설정 | 제목, 일시, 장소, 강사, 소개, 일정표, 맨 아래 문구 |

## 알아둘 점

- 새 글과 설문은 선생님 화면이 15초마다 확인해서 나타납니다. 간격은 `public/assets/app.js` 맨 위의 `POLL_MS` 값(밀리초)으로 바꿀 수 있습니다. 값을 키우면 넷리파이 함수 호출 수가 줄어듭니다.
- 설문 응답은 기기마다 하나로 셉니다. 같은 기기에서 다시 응답하면 앞의 응답이 바뀝니다. 응답자 이름은 저장하지 않습니다.
- 관리자 비밀번호는 환경 변수에만 있고 파일에는 없습니다. 비밀번호를 바꾸려면 환경 변수를 고치고 다시 배포하세요.
- 사이트는 검색엔진에 나오지 않도록(noindex) 설정돼 있습니다.
- 내 컴퓨터에서 시험하려면 `npx netlify dev`를 실행합니다.
